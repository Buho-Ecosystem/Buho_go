# Nostr Icons (community set)

Official icon set from the Nostr Design Guide: https://nostrdesign.org/docs/resources/#nostr-icons

Downloaded 2026-07-26. The `Nostr-Icons.zip` link on the site 404s (the file
lives in the repo's `docs/` folder, which Docusaurus never publishes), so it
came from the source repo instead:

    https://raw.githubusercontent.com/nostrdesignguide/nostrdesignguide.github.io/main/docs/resources/Nostr-Icons.zip

Live Figma equivalent (production-ready icons and buttons):
https://www.figma.com/file/vaWDSKYGlRu7yEmKlxtt6S/Nostr-Icons-%26-Buttons

## Layout

    Light/   white artwork, for dark backgrounds
    Dark/    black artwork, for light backgrounds
      PNG/ and SVG/, each in 24x24 and 32x32

## What each mark is

| File | Mark | Notes |
| --- | --- | --- |
| `nostrich-head-*` | Ostrich head with the large eye | Bare silhouette, no container. Best candidate for small badges since it can be knocked out of a colored disc. |
| `nostrich-*` | Full running ostrich | Detailed, loses legibility below roughly 24px. |
| `nostr-head` | Ostrich knocked out of a filled square | Same silhouette as `../nostr.png`, which is the purple version of this mark. |
| `shaka-*` | Shaka hand sign | Culturally iconic on Nostr, but does not read as "Nostr" to newcomers. |
| `Original-logo` | Broken export | Contains only two rectangles (a filled square plus a white band). Not usable. |

## Licensing

The set is described upstream as community-created, and no explicit license is
attached. Nostr has no single agreed logo, so the guide leaves the choice of
mark to each app.
