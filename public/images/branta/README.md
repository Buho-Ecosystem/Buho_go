# Branta wordmark

The light-background SVG is Branta's original wordmark from:
https://www.branta.pro/brand/wordmark-on-light.svg

It was reviewed with CoinSnap PR #147 and the approved BuhoGO HTML proposal.
The original paths, proportions and colors are retained. It is bundled so
the verification explanation does not request provider branding over the
network. A light plate preserves its original colors in the dark theme;
the mark is not filtered or recolored.

Brand usage guidance: https://www.branta.pro/brand
